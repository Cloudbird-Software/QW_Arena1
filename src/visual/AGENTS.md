# src/visual —— 视觉管线模块（IR-0001）

## 职责

视觉质量核心件的提示词资产与查询面：品类构图模板（W1）、市场视觉词典（W2）等
以可枚举配置资产落地（INV-3），经本模块入口对外提供查询。

## 不变量

- 全部视觉控制点（构图/词典/负面提示词/阈值）必须是可枚举的数据资产或代码规则，
  禁止散落于自由文本。
- 跨模块只能 import 本目录 `index.ts`，禁止深入 `compositions.ts` 等内部实现。

## 禁止

- 不做像素级图像处理（渲染归本地渲染件，W5）。
- 不内嵌任何密钥、客户名或连接串。
