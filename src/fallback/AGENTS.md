# src/fallback —— 单级兜底模块（IR-0001 W6）

## 职责

主路径失败（生成失败 / 质检重生成超限）后的单一兜底计划：图片=源图裁剪加
本地合成，视频=图片轮播。策略表在 strategies.ts（可枚举资产）。

## 不变量

- 单级兜底：每种媒体类型恰一条策略，禁止多级模型轮换降级路径（BEH-6）。
- 兜底路径零模型调用（usesModelCall 恒为 false）。

## 禁止

- 不引入备用模型调用或模型优先级链。
- 不做像素级合成实现（执行层职责，本模块只产出计划）。

## 独立验证

`make test tests/card-11-w6-single-fallback.test.ts`
