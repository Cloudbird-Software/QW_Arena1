# XHS 真实电商/种草视频基准研究（FashionVideo/xhs_video_data）

研究时间：2026-08-29。样本：`data.jsonl` 全量 35,052 行统计 + 随机 40 条视频逐条看片（接触表 5 张 + 标杆全帧细看）。
本文件是 v3.5.2 视频链路改造的依据，也是红队评分视频维度的 oracle。

## 1. 数据集概况

- 来源：HuggingFace `FashionVideo/xhs_video_data`（CC BY-NC 4.0），经 hf-mirror.com 下载（huggingface.co 在本机 DNS 污染不可达）。
- 35,052 行 = 11,684 条独立视频 × 3 种参考图设定（sr=原图复刻 / edit1 / edit2 换装编辑）。
- 视频与参考图均托管于阿里云 OSS（alimama-creative-public），直链无签名可下载。
- prompt 字段 = 中文视频动作标注（初始姿态 + 动作过程两段式），是现成的"动作语料库"。
- ⚠️ 注意：视频全部位于 `lihaijin/condition_s2v/wan25/` 路径，即该数据集本身是 Wan2.5 s2v/i2v 的训练/评测条件视频集——**它就是阿里官方生态里"合格的女装视频"长什么样**，作为对齐目标非常正当。

## 3. 动作语汇（核心发现，按频率排序）

1. **转身展示链**（最高频，~8/40）：站立 → 缓慢转身（正面→侧面→背面）→ 常以回眸收尾。样本 010/000/004/013/019/025/039。这是"让买家看到衣服全角度"的电商本质动作。
2. **走动 + 回眸**（~5/40）：向镜头/ away 走几步，回头看镜头。002/022/032/034。
3. **面料/裙摆动态**（伴随转身或单独）：裙摆随转身展开、面料轻摆。019/025/039/000。
4. **与镜头互动**（灵魂特征）：直视镜头、微笑、回眸。008/014/022。
5. **微动作**（几乎全体）：抬手整理头发/帽子/包、手抚衣身——让画面"活"的小幅度手部动作。
6. **坐姿姿势流**（~6/40）：床上/咖啡店/台阶，重心与手位缓变。005/014/020/038。
7. **自拍视角**（3/40）：对镜自拍式。016/021/037。
8. **配饰/细节特写**（少数）：008 红光下手腕手表/手链特写、026 choker 特写。

## 5. 对我方视频（v3.5.1：10s 单镜头 i2v，静止机位+面料轻摆）的判定

**形态上我们已正确**：单镜头、竖屏、全身景别、真实场景——与数据集主流一致。**handoff §4 预判的"单镜头 vs 蒙太奇"张力被证伪**：真实 XHS 女装视频就是单镜头（无剪辑），我们不需要也无法做剪辑，形态无差距。

**真正差距在动作内容**（这是 v3.5.2 要改的）：
1. 我们的动作（静止机位+面料轻摆）过于保守——真实视频有"转身全角度展示"这个电商核心动作，我们一个转身都没给。买家看不到背面 = 电商可用性实打实的缺口。
2. 我们没有与镜头的互动（回眸/直视）——真实视频的灵魂特征。
3. 我们没有手部微动作——画面偏"死"。
4. 音轨：40/40 有 vs 我们——**差距实际已关闭（2026-08-29 红队实测修正）**：Wan i2v 产物自带真实 mp4a 音轨（44.1kHz AAC 环境音 + udta AIGC 溯源标记），文档声明 model-generated ambient audio 属实。
5. 口播字幕：不可修复（无文字渲染资格，A1 风险），披露。

## 6. v3.5.2 改造方向（motionchain flag）

1. **裙装/裙类商品 → 转身展示链**：MOTION_PROMPT 从"静止+轻摆"升级为"缓慢完整转身展示正面与背面 → 收尾回眸镜头"。词汇从数据集 prompt 语料提炼（自然、低幅度、连续）。
2. **非裙装 → 保守升级**：保持静止机位，加"手部轻抚衣身/袖口微动作 + 直视镜头"。
3. **首帧选择联动**：转身链要求首帧正面全身、配饰负担低——divsel 已有该逻辑，沿用。
4. **风险控制**：转身 = 人脸背面/侧面帧增多，伪影风险高于静止；已有双通道 QC + 重试梯子（同档重生成→5s→预置兜底）保护，QC 判据不变。
5. vidcap 视频描述同步按实际动作链渲染（诚实描述，不许描述与实物脱节）。

## 7. 复现方式

- `data.jsonl`（41MB 全量元数据）、`sample_download.py`（抽样下载）、`mp4_stats.py`（纯 stdlib mp4 探针）、`make_sheets.py`（接触表+音轨响度）。
- 样本在 `sample/`（40 视频 + 40 参考图 jpg），接触表在 `sheets/`。
- 全量 11,684 视频按需再下（OSS 直链稳定，约 6GB 全量，无必要不建议）。
