# v3.5.2 视频红队评分协议（XHS 真实视频基准版）

对象：CNB 官方环境运行的 v3.5.2 真实产物（六图 + product_video.mp4）。
基准：`benchmark_videos/xhs_ref/FINDINGS.md`（40 条真实小红书女装视频逐条看片的结论）+ 标杆片 010/000/022/019/14。
红队纪律：**先用眼睛看，再下结论**（Read 视频逐帧 + 对照同目录参考截图）；指控必须给出具体秒数与画面证据；不确定的标注"存疑"而非"确认"。

## 一、电商可用性七问（对照 XHS 基准，视频维度）

1. **背面可见性**：XSS 基准的主流动作是转身展示（正面→背面→回眸）。本片是否让买家看到服装背面？若转身链未生效（prompt 分档未命中/首帧非正面），如实记录并降级评估。
2. **动作自然度**：转身是否连贯？有无滑步、漂移、瞬间换位（i2v 位移伪影）？对照标杆 010 的动作节奏（5 秒一次完整转身）。
3. **面料动态**：裙摆/衣料是否随动作自然摆动（XHS 灵魂特征）？还是僵硬纸片感？
4. **与镜头互动**：收尾是否有回眸/直视镜头？表情是否自然？
5. **全身信息完整性**：买家能否看清领型/袖型/长度/轮廓？有无特写裁切丢失全身信息？
6. **时长与节奏**：10 秒内动作分布是否合理（XHS 5 秒完成一次转身；我们 10 秒应完成 1-2 次动作链不显拖沓）？
7. **音轨缺失披露**：真实视频 40/40 有音轨，我们无音轨——文档（Video Description/策略文档）是否如实声明"model-generated ambient audio / 无第三方音乐"而非谎称有 BGM？

## 二、伪影零容忍清单（沿 v3.2.0 全片严格质检口径，双通道漏网的逐帧抓）

手表/首饰复制或瞬移；手指数量/粘连/变形；纽扣间距错位；面料纹理融化/泳动；块状噪点；背景条带；文字/乱码；肢体扭曲（转身过程高发：腰部扭转不连续、腿部穿模、颈部断裂感）。

## 三、图片维度四问（对照 Livostyle/H&M/AliExpress 三重基准）

1. 主图是否白/浅灰棚拍（H&M 印证）？色名与 SKU 一致？
2. 六图是否有近似重复（同机位同姿势）？
3. UI 残留/文字/水印/拼图是否为零？
4. 文档（Image Descriptions/选图记录/Media File Mapping）与实际六图字节一致？

## 四、评分卡（每项 0-10，附一句证据）

| 维度 | 权重 | 10 分标准 |
|---|---|---|
| 背面可见性/动作链 | 25% | 完整转身+回眸，节奏对标 010 |
| 伪影清洁度 | 30% | 整段时间轴零命中清单二 |
| 面料/肢体自然度 | 20% | 面料摆动真实、转身无扭曲 |
| 镜头互动/电商观感 | 15% | 有回眸或直视，构图稳定 |
| 文档诚实一致 | 10% | 描述与实际动作/首帧槽位/音轨口径完全一致 |

≥8.5 = 优秀（无需迭代）；7.5-8.5 = 良好（列改进点评估）；<7.5 = 必须迭代。
败诉条款：任何"确认级"伪影命中 → 无论总分直接迭代（重生成或 prompt 修正）。
