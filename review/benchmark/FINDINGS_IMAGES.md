# 真实女装电商图片基准研究（Livostyle + H&M）

研究时间：2026-08-29。样本：Livostyle 目录 40 张（真人模特实拍）+ H&M 40 张（官方商品图），子代理采集（fashion_img/sample/ + sheets/），主代理逐张审阅接触表。

## 数据集

- `arturayupov/womens-fashion-catalog`（Livostyle，美国 DTC 女装目录，2766 商品）：images.parquet 只存 Shopify CDN URL；按 product_type 过滤连衣裙/上衣类 452 个在售商品取 40 张。**风格 = 真人模特场景实拍**：正面站姿为主，生活化背景（墙边/户外/彩色门/绿植），自然光，微笑表情，自然手部动作（插袋/扶帽/端咖啡），姿势有侧身/坐姿/回眸变化。
- `srpone/hm-eval`（H&M 真实目录检索基准，2000 queries 内嵌图）：**风格 = 纯白/浅灰棚底平铺 + 隐形人台**，无模特出镜，光线均匀一致，商品居中完整。
- 弃用：Humanbased-AI/Fashion-1K（无人类模特）、infinite-dataset-hub/DeepFashionCatalog（AI 生成内容）、Codatta/Fashion-1K（不存在）。

## 对照我方 v3.5.2 六槽结构的判定

| 我方策略 | 真实基准印证 | 判定 |
|---|---|---|
| main = 白/浅灰棚拍正面优先 | H&M 全部如此；Livo 少数纯色棚拍 | ✓ 维持 |
| detail_1 = 细节/微距 | 两大目录均有质感特写类图 | ✓ 维持 |
| detail_2–5 = 异色正面/场景 | Livo 的彩色模特场景图（多色覆盖） | ✓ 维持 |
| 图内零文字/零水印/零拼图 | H&M/Livo 均无文字叠加 | ✓ 维持 |
| 背面/侧面类别缺口如实记录 | 源数据无背面图（v3.3.0 12 次 VL 判定证实） | 数据上限，维持如实披露 |

**结论：图片侧选图策略与真实电商目录形态一致，无新杠杆，本次不改动图片链路。** 优化重心 = 视频 motionchain（转身链）。

## 与 XHS 视频基准的互相印证

Livo 模特图的姿势语汇（手插袋、扶帽、侧身、回眸）与 XHS 视频的动作语汇同源——视频转身链 + 图片姿势多样性共同构成"真实电商审美"。我方图片 VL pose 字段已用于描述差异化（vidcap）。
